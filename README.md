# Ellinika

Native iPhone-App (SwiftUI, iOS 17+) zum Neugriechisch-Lernen für Deutschsprachige.

- **Vokabeln:** Karteikarten mit Leitner-System, Quiz (GR→DE, DE→GR, Buchstaben), durchsuchbare Wortliste
- **Grammatik:** 6 Lektionen mit Erklärungen, Tabellen und Übungen
- **Gespräche:** 4 Übungsdialoge (offline) und freies Gespräch mit einer KI-Gesprächspartnerin (Claude API, eigener API-Schlüssel nötig)
- **Alphabet:** alle 24 Buchstaben mit Aussprache und Buchstabenkombinationen

Öffnen mit Xcode: `Ellinika.xcodeproj`, Schema „Ellinika“.
